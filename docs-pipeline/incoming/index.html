Product facts

  • The admin is a Tauri 2 / Svelte 5 thin client; no Django runs in the shipped app.
  • All CRUD UI derives from the drf-spectacular OpenAPI schema; token auth only.
  • AI assistant is OpenAI-compatible chat only, streaming via Ctrl+K; no history persistence.
  • Release builds carry a neutral brand (Admineverywhere); Freshorama identity is applied via brand.json.
  • Admin UI was removed from the public website origin on owner order (2026-11-01); the apps are the sanctioned surface.
